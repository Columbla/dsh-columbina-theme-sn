# 表情包 / Stickers

本目录随仓库附带了 12 张哥伦比娅表情（WebP）与一张欢迎页头像，**开箱即可用**。

## 换成自己的图

把图片放进本目录（`png` / `jpg` / `webp` / `gif` / `avif`，单张 ≤ 8MB），文件名与 `stickers.json` 里 `items[].file` 对应即可。

```json
{
  "id": "goodnight",
  "label": "晚安",
  "file": "meme/晚安.webp",
  "when": "仅深夜（23:00 后）收尾、劝用户去休息",
  "note": "合掌闭眼，蓝色蝶翼"
}
```

对不上的条目会进 `missing`，既不进人格正文，也不给预览，但不影响插件其他能力。

## 欢迎页头像

任何包内相对路径都可以，填进状态文件的 `hero.image` 即可；建议用带 alpha 的圆形 PNG（显示尺寸 72px）。`hero.image` 留空 = 不显示头像，只留一行标题。
