# 背景图 / Backgrounds

本目录随仓库附带 3 张预设背景，装完即有画面：

| 文件 | 说明 |
| --- | --- |
| `01-columbina-light.png` | 浅色主题的默认起点（按文件名排序第一张） |
| `02-columbina-dark.png` | 深色主题观感更好的一张 |
| `03-columbina-dusk.jpg` | 第三张预设 |

## 换成自己的图

- 支持：`png` / `jpg` / `jpeg` / `gif` / `webp` / `avif`
- 单张上限：**24 MB**
- 推荐：**2560×1440 或更大，16:9**
- 文件名只用于排序与显示，不会被执行；按文件名排序，第一张是默认起点
- 面板里的「上传背景图」会直接写进本目录，重名自动加序号，**永不覆盖**已有图片

加图 / 换图后刷新页面即可；面板的缩略图条会跟着重扫。
